Recover the sensor readings

A sensor records each true value plus one third of the previous true value:

ri = si + (1/3)si-1, with s-1 = 0. Here s is the true value and r is the recorded value. There is no wraparound or additional noise.

Recorded values: [9, 9, 5, 1, 6, 5].

On paper, design a way to recover all the true values and explain why it works for any sequence length. Show the whole transformation using equations, arrows, or a coefficient matrix. You will implement it with NumPy in Phase 2.
